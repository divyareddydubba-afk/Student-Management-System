# 🎓 Student Management System

## 📌 About the Project

Student Management System is a Java-based application designed to manage and organize student information efficiently. It provides a simple way to store, view, update, search, and delete student records.

This project is developed to reduce manual work and make student record management easier and more organized.

## 🚀 Features

- ➕ Add new student details
- 👀 View all student records
- 🔍 Search student details
- ✏️ Update student information
- 🗑️ Delete student records
- 📋 Manage student ID, name, course, age, and marks
- 📊 Display student information in an organized manner
